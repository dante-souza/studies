01 — Chamada à API e resposta em JSON

Trilha: 01 chamada e JSON → 02 saída estruturada → 03 enums e guardrails → intermediário → avançado

O exemplo que acompanha a trilha inteira: uma lista de compras gerada a partir de um prato. Aqui ele começa como no seu primeiro contato com a API: pedir JSON no prompt e ler com json.loads.

⚠️ O que ainda quebra (e o 02 resolve)

1. A quantidade é texto. "250 grams" mistura número e unidade. Para fazer a lista para 4 pessoas, o programa precisaria "adivinhar" onde está o número:

[8]
show(f"primeiro['amount'] * 2: {primeiro['amount'] * 2!r}")

primeiro['amount'] * 2: '250 grams250 grams'

Não deu erro — e esse é o problema: "250 grams" * 2 é "250 grams250 grams". Qualquer cálculo exige parsing manual, e o modelo pode escrever "250g", "0.25 kg" ou "2 xícaras".

2. O formato não é garantido. O prompt pede JSON; nada obriga o modelo a obedecer. Duas respostas que aparecem na prática (exemplos construídos):

[9]

    json.loads(com_cerca)

    show(f'lista_trocada[0]["ingredients"]: {lista_trocada[0]["ingredients"]}')

Resumo: pedir JSON no prompt dá um texto que parece dado. Falta um contrato: quais campos, de que tipos — e um jeito de conferir. ➡️ 02 — saída estruturada

02 — Saída estruturada com Pydantic

Trilha: 01 chamada e JSON → 02 saída estruturada → 03 enums e guardrails

De onde viemos: no 01, o JSON pedido no prompt veio com a quantidade como texto ("250 grams"), e nada garantia o formato. Aqui a lista de compras ganha um contrato: uma classe Pydantic que diz quais campos existem e de que tipo — e que confere a resposta.

from pydantic import BaseModel, ConfigDict, Field, ValidationError


class Ingrediente(BaseModel):
    model_config = ConfigDict(extra="forbid")
    nome: str
    quantidade: float = Field(gt=0, description="Quantidade numérica, sem unidade")
    unidade: str = Field(description="Unidade métrica: g, kg, ml, l ou un")


class ListaDeCompras(BaseModel):
    model_config = ConfigDict(extra="forbid")
    prato: str
    porcoes: int = Field(gt=0)
    ingredientes: list[Ingrediente]

Duas mudanças em relação ao 01: a quantidade é número e a unidade é um campo separado. O Pydantic gera, a partir da classe, o JSON Schema que descreve esse contrato — é isso que vai para o modelo:

2.3 Com pydantic-ai (o Agent do seu notebook)

O Agent faz o mesmo com menos código: recebe output_type=ListaDeCompras e devolve o objeto validado. (O OpenAIModel do exemplo original foi renomeado para OpenAIChatModel; o endpoint entra pelo OpenAIProvider.)

Pegadinha: dentro do Jupyter use await agente.run(...). O agente.run_sync(...) tenta abrir um event loop, e o kernel já tem um rodando: RuntimeError: This event loop is already running. Em script .py comum, run_sync funciona.

[8] API, executada com o .env
# api: pydantic-ai com o mesmo endpoint
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

modelo_pai = OpenAIChatModel(AI_MODEL, provider=OpenAIProvider(base_url=openai_base_url, api_key=api_key))
agente_compras = Agent(modelo_pai, output_type=ListaDeCompras,
                       instructions="Você gera listas de compras com ingredientes in natura e sistema métrico.")

    """Primeiro JSON (objeto ou lista) decodificável no texto, como texto, sem nada em volta. O que não é texto passa."""

Um assistente de lista de compras recebe de tudo. Em vez de torcer para o modelo "se comportar", o contrato obriga a resposta a declarar o tipo — e o código trata cada tipo explicitamente.

class TipoPedido(StrEnum):
    RECEITA = "receita"
    FORA_DO_ESCOPO = "fora_do_escopo"


class RespostaAssistente(BaseModel):
    model_config = ConfigDict(extra="forbid")
    tipo: TipoPedido
    lista: ListaDeCompras | None = None
    motivo: str | None = Field(default=None, description="Obrigatório quando tipo = fora_do_escopo")

    @model_validator(mode="after")
    def tipo_combina_com_conteudo(self):
        if self.tipo is TipoPedido.RECEITA and self.lista is None:
            raise ValueError("tipo 'receita' exige 'lista'")
        if self.tipo is TipoPedido.FORA_DO_ESCOPO and (self.lista is not None or not self.motivo):
            raise ValueError("tipo 'fora_do_escopo' exige 'motivo' e não aceita 'lista'")
        return self


def tratar(resposta: RespostaAssistente) -> str:
    match resposta.tipo:
        case TipoPedido.RECEITA:
            return f"Lista de {resposta.lista.prato}: {len(resposta.lista.ingredientes)} itens"
        case TipoPedido.FORA_DO_ESCOPO:
            return f"Só ajudo com listas de compras. ({resposta.motivo})"

O model_validator impede combinações sem sentido (tipo "receita" sem lista, por exemplo). Com isso, tratar pode confiar que resposta.lista existe no caso RECEITA.

4. O laço de conversa

Com ferramentas, uma pergunta vira várias rodadas: o modelo pede ferramentas, o código executa e devolve os resultados, e o modelo responde — ou pede mais. Uma configuração congelada (frozen) guarda os parâmetros do laço, incluindo um limite de rodadas.

A função que fala com o modelo entra como parâmetro (chamar_modelo): com a API real ou com respostas construídas, o laço é o mesmo. Cada execução de ferramenta vira um evento no log (GeneralLogger, de logger_general.py): INFO quando dá certo, WARNING quando o resultado é um erro que volta ao modelo.

@dataclass(frozen=True)
class ConfiguracaoChamada:
    modelo: str = "gpt-4o-mini"
    max_rodadas: int = 5
    instrucao: str = (
        "Você ajuda com compras de mercado. Use as ferramentas para consultar preços e a despensa. "
        "Responda em português, de forma curta."
    )


log = GeneralLogger(name="ferramentas", stream=sys.stdout)


def conversar(pergunta: str, chamar_modelo, config: ConfiguracaoChamada) -> str:
    mensagens = [{"role": "system", "content": config.instrucao}, {"role": "user", "content": pergunta}]
    for rodada in range(1, config.max_rodadas + 1):
        mensagem = chamar_modelo(mensagens)
        if not mensagem.tool_calls:
            return mensagem.content
        mensagens.append(mensagem.model_dump(exclude_none=True))
        for chamada in mensagem.tool_calls:
            resultado = executar_ferramenta(chamada.function.name, chamada.function.arguments)
            evento = f"rodada {rodada}: {chamada.function.name}({chamada.function.arguments}) -> {resultado[:60]}"
            (log.warning if '"erro"' in resultado else log.info)(evento)
            mensagens.append({"role": "tool", "tool_call_id": chamada.id, "content": resultado})
    raise RuntimeError(f"sem resposta final em {config.max_rodadas} rodadas")

1. As regras, como funções

Cada regra é uma função que recebe a lista e devolve uma lista de problemas (vazia = tudo certo). Mensagens claras importam: elas vão ser lidas pelo modelo no retry.

[3]
LIMITE_POR_PESSOA = {Unidade.G: 400, Unidade.KG: 0.4, Unidade.ML: 300, Unidade.L: 0.3, Unidade.UN: 4}
PORCOES_MIN, PORCOES_MAX = 1, 20


def regra_quantidade_por_pessoa(lista: ListaDeCompras) -> list[str]:
    problemas = []
    for item in lista.ingredientes:
        limite = LIMITE_POR_PESSOA[item.unidade] * lista.porcoes
        if item.quantidade > limite:
            problemas.append(f"{item.nome}: {item.quantidade:g} {item.unidade} passa do limite de {limite:g} {item.unidade} "
                             f"para {lista.porcoes} porções")
    return problemas


def regra_sem_duplicados(lista: ListaDeCompras) -> list[str]:
    nomes = [item.nome.strip().lower() for item in lista.ingredientes]
    repetidos = sorted({nome for nome in nomes if nomes.count(nome) > 1})
    return [f"ingrediente repetido: {nome}" for nome in repetidos]


REGRAS = [regra_quantidade_por_pessoa, regra_sem_duplicados]


def verificar_regras(lista: ListaDeCompras) -> list[str]:
    return [problema for regra in REGRAS for problema in regra(lista)]

3. Retry com feedback

pedir_lista junta tudo: valida o pedido, chama o modelo, valida o contrato e as regras. Se algo falhar, devolve ao modelo a resposta dele e a lista de erros, e tenta de novo — até max_tentativas. Cada tentativa vira um evento no log (WARNING quando falha, INFO quando passa).

A função tem duas saídas:

  • sucesso: o return ResultadoPedido(...) fica dentro do laço e encerra a função na primeira tentativa sem erros;
  • fracasso: se todas as tentativas falharem, o laço termina e a função levanta RuntimeError (não há retorno).

O ResultadoPedido é uma dataclass com a lista validada, o número da tentativa que deu certo e os erros de cada tentativa (uma lista por tentativa; a última é [], porque foi a que passou).

[6]
INSTRUCAO = "Você gera listas de compras com ingredientes in natura e sistema métrico, em quantidades realistas."


@dataclass
class ResultadoPedido:
    lista: ListaDeCompras
    tentativas: int
    erros_por_tentativa: list[list[str]] = field(default_factory=list)


def erros_da_resposta(texto: str) -> tuple[ListaDeCompras | None, list[str]]:
    try:
        lista = saida_llm(ListaDeCompras).validate_python(texto)   # borda: texto -> objeto, inclusive "sem JSON"
    except ValidationError as ex:
        return None, [f"{'.'.join(map(str, e['loc'])) or 'resposta'}: {e['msg']}" for e in ex.errors()]
    return lista, verificar_regras(lista)


log = GeneralLogger(name="retry", stream=sys.stdout)


def pedir_lista(prato: str, porcoes: int, chamar_modelo, max_tentativas: int = 3) -> ResultadoPedido:
    validar_pedido(prato, porcoes)
    mensagens = [
        {"role": "system", "content": prompt_com_schema(INSTRUCAO, ListaDeCompras)},
        {"role": "user", "content": f"{prato} para {porcoes} pessoas"},
    ]
    historico = []
    for tentativa in range(1, max_tentativas + 1):
        texto = chamar_modelo(mensagens)
        lista, erros = erros_da_resposta(texto)
        historico.append(erros)                                  # erros desta tentativa ([] se passou)
        if not erros:
            log.info(f"tentativa {tentativa}: lista válida ({len(lista.ingredientes)} itens)")
            return ResultadoPedido(lista, tentativa, historico)  # saída 1 (sucesso): encerra a função aqui, no meio do laço
        log.warning(f"tentativa {tentativa}: {'; '.join(erros)}")
        mensagens.append({"role": "assistant", "content": texto})
        mensagens.append({"role": "user", "content": "A resposta tem problemas. Corrija e devolva o JSON completo:\n- "
                                                     + "\n- ".join(erros)})
    # saída 2 (fracasso): só chega aqui se nenhuma tentativa passou
    raise RuntimeError(f"{max_tentativas} tentativas sem resposta válida; últimos erros: {historico[-1]}")

class ContextoPedido:
    orcamento: Decimal

    despensa: Mapping[str, tuple[Decimal, Unidade]] = field(default_factory=dict)

Ele confere o limite por pessoa (a regra do 05), desconta a despensa, calcula o custo do que falta comprar e compara com o orçamento. O custo calculado fica num atributo privado — só existe em listas que passaram pela validação.

[5]
class ListaComContexto(ListaDeCompras):
    _custo: Decimal | None = PrivateAttr(default=None)

    @model_validator(mode="after")
    def regras_com_contexto(self, info: ValidationInfo):
        ctx = info.context
        if not isinstance(ctx, ContextoPedido):
            raise ValueError("contexto obrigatório: valide com context=ContextoPedido(...)")
        problemas, total = [], Decimal(0)
        for item in self.ingredientes:
            quantidade = Decimal(str(item.quantidade))
            limite = ctx.limite_por_pessoa[item.unidade] * self.porcoes
            if quantidade > limite:
                problemas.append(f"{item.nome}: {quantidade} {item.unidade} passa do limite de {limite} {item.unidade}")
                continue
            falta = quantidade
            if item.nome in ctx.despensa:
                tem, unidade_casa = ctx.despensa[item.nome]
                falta = max(Decimal(0), quantidade - converter(tem, unidade_casa, item.unidade))
            if falta == 0:
                continue
            if item.nome not in ctx.precos:
                problemas.append(f"{item.nome}: sem preço na tabela")
                continue
            preco, unidade_venda = ctx.precos[item.nome]
            try:
                total += preco * converter(falta, item.unidade, unidade_venda)
            except ValueError as ex:
                problemas.append(f"{item.nome}: {ex}")
        total = total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
        if total > ctx.orcamento:
            problemas.append(f"custo R$ {total} passa do orçamento de R$ {ctx.orcamento}")
        if problemas:
            raise ValueError("; ".join(problemas))
        self._custo = total
        return self

    @property
    def custo(self) -> Decimal:
        return self._custo

class Decisao(StrEnum):
    PERMITIR = "permitir"
    NEGAR = "negar"
    CONFIRMAR = "confirmar_com_humano"


def decidir(perfil: Perfil, nome_ferramenta: str) -> tuple[Decisao, str]:
    try:
        ferramenta = Ferramenta(nome_ferramenta)
    except ValueError:
        return Decisao.NEGAR, f"ferramenta desconhecida: {nome_ferramenta}"
    exigida = CAPACIDADE_EXIGIDA.get(ferramenta)
    if exigida is None:
        return Decisao.NEGAR, f"{ferramenta} sem capacidade mapeada"
    if perfil not in PERMISSOES or exigida not in PERMISSOES[perfil]:

    if exigida & EXIGE_CONFIRMACAO:
        return Decisao.CONFIRMAR, "ação irreversível"
    return Decisao.PERMITIR, "ok"

2. Medindo tempo

Um Span por etapa, aberto e fechado por um context manager. perf_counter é o relógio certo para medir duração (é monotônico; time.time() pode pular quando o relógio do sistema é ajustado).

@dataclass
class Span:
    nome: str
    inicio: float
    fim: float | None = None

    @property
    def duracao_ms(self) -> float:
        return ((self.fim or perf_counter()) - self.inicio) * 1000


@dataclass
class Rastreio:
    spans: list[Span] = field(default_factory=list)

    @contextmanager
    def medir(self, nome: str):
        span = Span(nome, perf_counter())
        self.spans.append(span)
        try:
            yield span
        finally:
            span.fim = perf_counter()

3. Histórico com orçamento de tokens

Enviar a conversa inteira toda vez fica caro e, um dia, passa do limite do modelo. O histórico guarda tudo, mas envia só o que cabe no orçamento: o prompt de sistema e os turnos mais recentes.

Um turno começa numa mensagem do usuário e inclui tudo até a próxima: as chamadas de ferramenta do assistente e os resultados. Cortar no meio de um turno separaria um resultado da chamada que o pediu (pegadinha 1).

[5]
def tokens_da_mensagem(mensagem: dict) -> int:
    return estimar_tokens(str(mensagem.get("content") or "") + json.dumps(mensagem.get("tool_calls") or ""))


@dataclass
class Historico:
    sistema: dict
    mensagens: list[dict] = field(default_factory=list)

    def turnos(self) -> list[list[dict]]:
        turnos: list[list[dict]] = []
        for mensagem in self.mensagens:
            if mensagem["role"] == "user" or not turnos:
                turnos.append([])
            turnos[-1].append(mensagem)
        return turnos

    def para_envio(self, orcamento_tokens: int) -> list[dict]:
        restante = orcamento_tokens - tokens_da_mensagem(self.sistema)
        escolhidos: list[list[dict]] = []
        for turno in reversed(self.turnos()):
            custo = sum(tokens_da_mensagem(m) for m in turno)
            if custo > restante and escolhidos:
                break
            escolhidos.insert(0, turno)
            restante -= custo
        return [self.sistema] + [m for turno in escolhidos for m in turno]

                self.historico.mensagens.append(mensagem.model_dump(exclude_none=True))
                if not mensagem.tool_calls:
                    return mensagem.content

Etapas: chave de idempotência → cache → classificar → rotear (com a política do 08) → gerar lista com contexto (07) → registrar uso (09). O match em IntencaoAberta cobre todos os membros, incluindo DESCONHECIDO, e termina em assert_never.

Cada etapa registra um evento estruturado (pedido, status, detalhe já redigido). Com console_log, os eventos também aparecem no console pelo GeneralLogger de logger_general.py: INFO para o fluxo normal, WARNING para recusa, incerteza ou falha.

@dataclass(frozen=True)
class Resultado:
    intencao: IntencaoAberta
    resposta: str
    custo_lista: Decimal | None = None
    do_cache: bool = False
    status: str = "respondido"  # respondido | recusado | incerto | falhou


@dataclass
class Pipeline:
    cliente: object
    cfg: Configuracoes
    precos: dict
    despensa: dict = field(default_factory=dict)
    cache: dict[str, Resultado] = field(default_factory=dict)
    uso: Uso = field(default_factory=Uso)
    eventos: list[dict] = field(default_factory=list)
    console_log: object | None = None  # GeneralLogger opcional: eventos também no console

    def chave(self, pedido: Pedido) -> str:
        normalizado = pedido.model_dump(mode="json") | {"texto": " ".join(pedido.texto.lower().split())}
        return hashlib.sha256(json.dumps(normalizado, sort_keys=True).encode()).hexdigest()[:16]

    def _chamar(self, instrucao: str, texto: str) -> str:
        resposta = self.cliente.chat.completions.create(
            model=self.cfg.modelo,
            messages=[{"role": "system", "content": instrucao}, {"role": "user", "content": texto}],
        )
        self.uso.registrar(resposta.usage)
        return resposta.choices[0].message.content

    def _registrar(self, chave: str, status: str, detalhe: str) -> None:
        evento = {"pedido": chave, "status": status, "detalhe": redigir(detalhe)}
        self.eventos.append(evento)
        if self.console_log is not None:
            nivel = "INFO" if status in ("recebido", "cache", "respondido") else "WARNING"
            self.console_log.log(nivel, f"pedido {chave} | {status:<10} | {evento['detalhe'][:70]}")

    def executar(self, pedido: Pedido) -> Resultado:
        chave = self.chave(pedido)
        self._registrar(chave, "recebido", f"[{pedido.perfil}] {pedido.texto}")
        if chave in self.cache:
            self._registrar(chave, "cache", "resposta reaproveitada, sem chamar o modelo")
            return replace(self.cache[chave], do_cache=True)
        resultado = self._processar(pedido)
        self.cache[chave] = resultado
        self._registrar(chave, resultado.status, f"{resultado.intencao} -> {resultado.resposta}")
        return resultado

    def _processar(self, pedido: Pedido) -> Resultado:
        texto = self._chamar(prompt_com_schema(INSTRUCAO_CLASSIFICAR, Classificacao), pedido.texto)
        c = saida_llm(Classificacao).validate_python(texto)
        if c.confianca < LIMIAR_CONFIANCA:
            return Resultado(c.intencao, f"não tenho certeza do pedido (confiança {c.confianca:.2f}); pode reformular?",
                             status="incerto")
        match c.intencao:
            case IntencaoAberta.RECEITA:
                return self._receita(pedido, c)
            case IntencaoAberta.PRECO:
                return self._preco(pedido, c)
            case IntencaoAberta.FORA_DO_ESCOPO:
                return Resultado(c.intencao, "só ajudo com compras de mercado", status="recusado")
            case IntencaoAberta.DESCONHECIDO:
                return Resultado(c.intencao, "não entendi o pedido; pode reformular?", status="incerto")
            case _:
                assert_never(c.intencao)

    def _preco(self, pedido: Pedido, c: Classificacao) -> Resultado:
        decisao, motivo = decidir(pedido.perfil, Ferramenta.CONSULTAR_PRECO)
        if decisao is not Decisao.PERMITIR:
            return Resultado(c.intencao, f"não posso consultar preço: {motivo}", status="recusado")
        if c.ingrediente not in self.precos:
            return Resultado(c.intencao, f"não tenho preço de {c.ingrediente!r}")
        preco, unidade = self.precos[c.ingrediente]
        return Resultado(c.intencao, f"{c.ingrediente}: R$ {preco} / {unidade}")

    def _receita(self, pedido: Pedido, c: Classificacao) -> Resultado:
        ctx = ContextoPedido(orcamento=pedido.orcamento or self.cfg.orcamento_padrao, precos=self.precos,
                             despensa=self.despensa)
        instrucao = prompt_com_schema(INSTRUCAO_LISTA, ListaDeCompras) + f"\nO custo não pode passar de R$ {ctx.orcamento}."
        erros = []
        for _ in range(self.cfg.max_tentativas):
            pedido_texto = f"{c.prato} para {pedido.porcoes} pessoas" + (f"\nCorrija: {erros[-1]}" if erros else "")
            try:
                lista = saida_llm(ListaComContexto).validate_python(self._chamar(instrucao, pedido_texto), context=ctx)
            except ValidationError as ex:
                erros.append(ex.errors()[0]["msg"])
                continue
            return Resultado(c.intencao, f"lista de {lista.prato}: {len(lista.ingredientes)} itens", lista.custo)
        return Resultado(c.intencao, f"não consegui montar a lista: {erros[-1]}", status="falhou")
